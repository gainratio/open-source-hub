Safe Local Agents

Coding agents routinely hit three production walls: losing signed-in browser state in fresh headless sessions, leaving half-finished writes when step four of five fails, and reading records outside their scope without provenance. These three small MIT repositories fix each failure mode on your own machine.

What happens in each 10-second segment

Segment 1 (0:00 – 0:10): Consent-gated live browser tabs (agentic-tab-context)

Conventional browser automation spawns an isolated browser profile with no SSO cookies, forcing developers either to log in again on every run or to hand raw session secrets to a script. Agentic Tab Context keeps your existing browser window in charge. Until you select a tab in the Manifest V3 Shared Tabs side panel or toolbar popup, the local daemon refuses agent bind requests with TAB_NOT_SHARED. Once shared, atc inspect reads the accessibility tree over local native messaging while automatically redacting password inputs, and atc click acts directly inside the authenticated tab without opening a second window.

Segment 2 (0:10 – 0:20): Newest-first Temporal compensation (agentic-saga)

Tool-calling loops make forward actions easy and partial-failure cleanup treacherous: you never want an LLM improvising whether a timed-out payment call succeeded or in what order to refund a card and release inventory. In the captured run, the checkout workflow reserves inventory, charges the card, and books fulfillment on a local Temporal server before the final carrier check fails. Deterministic Python rules immediately transition the workflow to compensating, cancel the delivery, refund the payment, release the item in strict reverse order, and record compensated_verified so nothing is left half-done.

Segment 3 (0:20 – 0:30): Pre-retrieval access control and provenance (agentic-context-service)

When multiple assistants share company knowledge through ad-hoc vector stores or prompt scratchpads, internal margin targets leak to customer-facing bots and nobody can audit which record produced an answer. In the captured run, the pricing assistant asks for the discount limit on item NS-100: the service checks the HMAC signature, blocks 4 of 7 unauthorized records before search, and returns the 20% rule citing record NS-100, edit number 7. When the customer-help assistant asks the exact same question, the internal 20% rule is filtered out before ranking so only the public 15% promotion is returned; when it tries to open pricing rules directly, Open Policy Agent refuses with 403 POLICY_DENIED.

Reproduce every segment on your own machine

None of the three demos requires an API key, cloud account, or external network service:

# 1. Agentic Tab Context (Node >= 22, Chrome / Brave / Edge / Firefox)
git clone https://github.com/gainratio/agentic-tab-context.git
cd agentic-tab-context && npm ci && npm run build && node bin/atc.js setup

# 2. Agentic Saga (uv — starts a throwaway local Temporal server + live flight recorder)
git clone https://github.com/gainratio/agentic-saga.git
cd agentic-saga && uv run poe demo

# 3. Agentic Context Service (uv — starts local HMAC + OPA policy demo on 127.0.0.1)
git clone https://github.com/gainratio/agentic-context-service.git
cd agentic-context-service && make demo

Python packages are also published on PyPI (agentic-saga and agentic-context-service), and the Chrome / Firefox Manifest V3 extension archive lives in store/agentic-tab-context-0.5.0.zip inside gainratio/agentic-tab-context.
