@gainratio/browser

The browser runtime for data that must be provably yours and unaltered. It syncs a signed, content-addressed bundle, verifies it locally, stores it in OPFS, and keeps it searchable offline.

What it provides

  • Signed bundle sync with Ed25519 verification and a rollback floor
  • Content-defined chunking and only-changed-chunk downloads
  • OPFS storage and SQLite with FTS5 and sqlite-vector search
  • Offline operation after the first sync
  • One Worker-owned SQLite connection with a bounded memory profile

Used by

EdgeReco for on-device product search, and AML-Filter for in-browser sanctions screening.

Install

npm install @gainratio/browser
